# Code of conduct

Yida AI welcomes respectful technical discussion and contributions from people
of every background and experience level.

## Expected behavior

- Discuss code, evidence and user impact without personal attacks.
- Respect privacy. Never post real captions, customer records, documents,
  credentials or identifying information in an issue or pull request.
- Give actionable feedback and allow contributors to correct mistakes.
- Disclose conflicts of interest and third-party code or data sources.
- Follow the security-reporting process for vulnerabilities.

Harassment, threats, discrimination, doxxing, sexualized conduct, deliberate
misrepresentation and repeated disruption are not accepted in project spaces.

## Enforcement

Report conduct concerns privately through the maintainer's GitHub profile or,
when the concern is security-related, through the repository's private security
reporting channel. The maintainer may edit or remove content, lock a discussion,
reject a contribution or restrict participation. Reports are handled as
confidentially as practical, with conflicts disclosed and avoided.
