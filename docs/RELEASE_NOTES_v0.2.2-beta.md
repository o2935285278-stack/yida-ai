# 译答 AI v0.2.2-beta

这是面向 Windows 11 的新手可用测试版。译答 AI 读取 Windows 实时字幕与
LiveCaptions Translator 的输出，结合最近对话、场景配置和本地资料，生成翻译
与较短的 AI 建议回复。

## 本版重点

- 支持简体中文、美国英语、巴西葡语及六个双向翻译组合。
- 分离识别语言、翻译显示语言、AI 回复语言和界面语言。
- 新增“一键启动”与统一状态提示，不会偷偷重启用户已关闭的组件。
- 首次启动检查 Windows 版本、实时字幕模型、Windows Update/BITS、磁盘、
  麦克风权限与音频设备，并针对 `0x80070422` 提供修复指引。
- 新增诊断与修复页，以及不包含字幕、回复、资料正文和 API Key 的诊断包。
- 修复重复翻译、断句完整性、长葡语文本和高 DPI 布局问题。
- API Key 可使用 Windows DPAPI CurrentUser 加密保存，不写入 JSON 配置。
- 为未来正式代码签名预留 SHA-256、RFC 3161 时间戳与 SignTool 验证流水线。

## 安装

1. 下载 `YidaAI-0.2.2-beta-win-x64-setup.exe`。
2. 在 Windows 11 x64 上运行安装程序。
3. 按首次启动向导选择界面语言和当前听取语言，并完成 Windows 实时字幕模型检查。
4. 在设置页填写兼容 OpenAI API 的地址、模型和你自己的 API Key。
5. 点击“一键启动”，确认状态显示正在监听后开始使用。

## 重要说明

当前安装包未进行可信代码签名，Windows 可能显示 SmartScreen 提示。本版本为
beta，不承诺零延迟、完全准确或混合中英葡语同时识别。译答 AI 不内置微软语言
包；缺少实时字幕识别模型时请按软件指引通过 Windows 官方流程安装。

LiveCaptions Translator 为 Apache-2.0 上游组件，本项目保留其原始文件、许可证
和归属，不使用译答 AI 证书重新签署它。
